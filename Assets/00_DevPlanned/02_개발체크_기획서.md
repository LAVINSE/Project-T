# Project T 개발 체크

수정일: 2026-09-25 · 버전: 0.29

[게임 규칙](01_전체세부_기획서.md) · [변경 기록](<03_신규콘텐츠 및 주요변경_기획서.md>)

이 문서는 구현 범위, 남은 개발, 착수 전 결정 항목, 사용자 확인 목록을 관리한다. 게임 규칙은 전체 기획서, 결정 사유는 변경 기록에만 적는다. **구현 완료와 실제 사용 확인을 구분한다.**

## 작업 진행 규칙

작업 방식·설계 원칙·코드 스타일은 My Unity Skills의 「유니티 게임개발 지침」을 따른다. 질문 후 답변 대기, 작업 전 확인, 선택지 제시, 기획서 일괄 갱신, 검증 코드·백업의 사전 승인이 여기에 포함된다. 아래는 이 프로젝트에만 적용하는 규칙이다.

1. 이미 승인한 규칙은 다시 미정으로 돌리지 않는다. 로드맵 등록을 다음 작업의 자동 승인으로 해석하지 않는다.
2. Unity 작업은 Unity CLI로 실행 중인 Editor에 연결해 진행한다. 장면·프리팹·자산 YAML을 직접 고치지 않는다.
3. 실제 사용 검증은 사용자가 진행한다. 개발 결과에는 컴파일 확인과 미확인 동작을 구분해 남긴다.
4. 삭제한 Tests와 시험 장면 자동 복제 기능을 다시 만들지 않는다. TestManager의 전투 시작·결과·재시작 버튼은 유지한다.

## 남은 개발 로드맵

기존 단계 0~7을 유지한다. 선행 기반이 구현된 항목은 다시 만들지 않으며 각 작업의 상세 내용은 착수 전에 확인한다.

| 단계 | 현재 상태 | 남은 개발 | 함께 만들 화면·편집 |
| --- | --- | --- | --- |
| 0. 전투 기반 | 구현, Pause 중 선택·이동 예약 추가 | 예약 이동/재개·장비와 입력 충돌 확인, 사용자 피드백 수정 | 기본 전투 조작·안내 |
| 1. 보상·보관 | 기반 구현 | 필요 시 획득 내역 요약 범위 결정. 새 정산 보상은 추가하지 않음 | 결과 내역·보상 데이터 편집 |
| 2. 특별 전리품 | 자동 획득으로 변경·구현 | 사용 확인 후 필요한 수정 | 인벤토리 아이콘 연출 |
| 3. 장비·제작 | 데이터·등급 추첨·2슬롯 장착/교체/해제·효과·종료 반환·전투 보조 능력치 공식 구현 | 장착 사용 확인, 발동형 능력, 설계도·재료 소비 제작 | 기존 HUD 장비 슬롯 확인, 필요 시 전후 능력치 비교, 제작 목록/결과 |
| 4. 영구 성장·재출전 | 미구현 | 공통 연구·클래스 성장·경험치·해금·저장 확장·거점 | 연구·클래스 성장·지역/스테이지 선택·출전 |
| 5. 선택·위협·연금 | 미구현 | 후보·발생·효과 수명, 위험/보상 배율, 맵별 파밍·경제 | 선택·위협·연금·목표 보상과 관련 데이터 편집 |
| 6. 고유 스킬 | 미구현 | 보유·해금·장착·교체·발동·성장 연동 | 스킬 목록·효과·대기시간·사용 불가 이유 |
| 7. 콘텐츠 확장 | 미착수 | 추가 맵·클래스·적·우두머리, 비교·일괄 편집·통합 확인 | 늘어난 목록·설명·아이콘·스크롤 |

우선 **인벤토리 자유 배치·장비 장착·Pause 조작의 실제 플레이 확인**을 진행하고 확인된 문제를 수정한다. 다음 신규 개발 후보는 설계도·제작과 발동형 장비 능력이며 착수 전에 상세 규칙을 정한다. 전투 보조 능력치 공식은 변경-042로 구현했다. 장착 방식·수량 점유·동일 장비 중복 금지·체력 변화·종료 반환은 이미 반영한 규칙이다. 스킬은 추후 구현으로 남긴다.

시작 화면, 진행 중 전투 이어하기, 출전 편성 방식, 설정 항목·소리·추가 조작 장치는 별도 결정 대기다. 출시 플랫폼 상세·가격·스팀 연동·배포 준비도 현재 단계에 포함하지 않는다.

### 이후 단계의 결정 항목

| 단계 | 필요한 결정 | 완료 기준 |

## 사용자 확인 목록

### 인벤토리 수동 테스트 사용

Play 후 `DontDestroyOnLoad`의 `TestManager` 인스펙터 버튼을 사용한다. 초기 상태에서는 자동 지급하지 않는다. 지급·제거 버튼은 실제 인벤토리 저장에 반영된다.

| 버튼 | 확인할 내용 |
| --- | --- |
| 인벤토리: 기본 더미 세트 지급 | 일반 아이템 6종과 장비 아이템 7종. 필터·1개/여러 개 버리기·아이콘 누락·특별 획득·긴 설명·판매가 |
| 인벤토리: 전체 더미 37종 지급 (스크롤) | 기본 13종과 재료 24종. 36칸 초과 스크롤. 버튼을 다시 누르면 새 요청으로 수량 합산 |
| 인벤토리: 마지막 지급 재요청 (중복 확인) | 같은 요청을 반복해도 수량·특별 획득 연출이 증가하지 않음. 저장 실패 시 같은 요청으로 재시도 |

| 인벤토리: 화면 열기 | 현재 전투의 인벤토리 표시 |

더미 자산은 `Assets/02_Res/Data/Testing/Inventory`, 테스트용 분류는 `Assets/02_Res/Data/Equipment/Categories/InventoryTest`에 둔다. ItemData 37종·EquipmentData 6종·공유 스탯 효과 1종이다. 장비는 0·1·2·5·8·12개 스탯과 일반/Rare/Epic/Unique/Legendary 외형을 비교한다. 희귀 검 C/B는 같은 장비 정의와 효과를 참조하며 공격력 +12/+20, 동일 장비 중복 제한을 비교한다. 특별 전리품·전설 장비는 소울, 나머지 더미는 전투 코인을 판매 재화로 연결했다. 아이콘 누락·긴 설명·가격 0/큰 값도 확인한다. 모든 더미 수치·가격은 기능 확인용으로 최종 밸런스가 아니며 정상 적 드롭에는 연결하지 않았다.

### 전투 공식 수동 테스트 사용

Play 후 TestManager의 「전투 공식 테스트」 그룹을 사용한다. 입력값을 실행 중 개체에만 임시로 더하며 데이터 자산은 바꾸지 않는다. 전투가 끝나면 사라진다.

| 버튼·항목 | 확인할 내용 |
| --- | --- |
| 전투 공식: 선택 아군에 테스트 능력치 적용 | 선택 아군에 치명타·흡수·관통·방어·회피를 적용한다. 기본 입력값은 치명 100%·흡수 50%다 |
| 전투 공식: 모든 적에 테스트 능력치 적용 (이후 생성 포함) | 현재 적과 이후 생성되는 적에 방어·회피를 적용한다. 기본 입력값은 방어 100이다 |
| 전투 공식: 테스트 능력치 모두 제거 | 테스트 증가량만 제거하고 장비 효과는 유지한다 |
| logHits | 켜면 타격마다 공격력·관통·대상 방어/회피·결과·흡수량을 콘솔에 남긴다 |

기준값(전사 공격력 18, 기본 해골 10): 모두 0이면 18·24·10, 치명 100%면 27, 적 방어 100이면 9, 방어 100과 치명 100%면 13.5, 방어 100과 관통 50이면 12, 아군 방어 100이면 해골 피해 5다.

아래 항목은 실행 결과를 확보하기 전까지 미확인으로 유지한다. 이 목록은 자동 테스트 코드 생성 지시가 아니다.

- [x] 우클릭 해제가 동작한다. 아이템 집기 취소용 우클릭이 장비 해제까지 실행하지 않는다.
- [ ] 같은 캐릭터의 두 슬롯에 같은 장비를 장착할 수 없다. 희귀 검 C/B도 중복으로 거부되며 같은 슬롯 C→B 교체는 가능하다.
- [ ] 여러 캐릭터가 같은 장비를 사용해도 보유 수량을 초과하지 않고 장착된 수량은 버리기·테스트 목록 제거에서 보호된다.
- [ ] 두 슬롯의 등급별/추가 스탯 효과가 해당 개체에만 적용되고 교체·해제 후 남지 않는다. 미지원 효과·잘못된 장비의 장착 실패는 기존 상태를 보존한다.
- [ ] 장비 변경으로 최대 체력이 늘어도 회복/부활하지 않고 감소 시에만 현재 체력이 제한된다. 교체 중 임시 감소가 생기지 않는다.
- [ ] 승리·패배·개발용 재시작·장면 종료 후 전체 장비를 다시 사용할 수 있고 종료 시점 통계는 장착 효과를 반영한다. 앱 재실행 후 총보유량도 유지된다.
- [ ] Pause 중 캐릭터를 선택하고 목적지를 지정해도 바로 이동하지 않으며 목적지 표시 후 정지 해제 시 이동한다.
- [ ] 여러 명의 예약과 같은 캐릭터의 최신 유효 목적지를 유지한다. 잘못된 명령은 기존 예약을 지우지 않으며 사망 중 지정한 목적지는 부활 후 사용한다.
- [ ] Pause 중 장착·교체·해제가 가능하고 신규 구매/배치·라운드 진행은 막힌다. 모든 정지 원인이 해제돼야 예약 이동을 시작한다.

스킬 교체는 구현하지 않았으므로 현재 확인 목록에 실행 항목으로 넣지 않는다.
